# proxylib

Shared, provider-neutral utility packages for proxy services (`codex-proxy`, `antigravity-proxy`).

## Packages

- **`accountid`**: Account identifier validation (1–32 character slug rules) and automatic slug derivation from email addresses.
- **`apikey`**: Cryptographically secure API key generation, SHA-256 hashing and constant-time matching, key ID generation, and immutable lookup registry.
- **`buildinfo`**: Executable build metadata resolution combining release linker variables, embedded base versions, and runtime VCS settings.
